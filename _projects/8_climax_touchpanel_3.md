## Introduction

**TouchPanel-3** is a 7” color graphic touchscreen panel that supports IP, LTE, WiFi (2.4GHz / 5GHz), and Z-Wave for home automation and security control. Designed to offer a comprehensive user experience, it allows users to manage devices, view real-time IP camera feeds, and interact through two-way voice communication. It also includes AI-based intruder detection and Bluetooth touchless disarming, making it a powerful all-in-one solution for modern smart homes.

🔗 [Official Website](https://www.climax.com.tw/touchpanel_3_page.php)

---

### 📌 Key Features

- **7-inch touchscreen** with intuitive UI  
- **IP / LTE / WiFi (2.4GHz / 5GHz)** connectivity  
- **Z-Wave Plus (800 Series)** home automation  
- **AI intruder detection** with 5.0MP front camera  
- **Two-way voice communication**  
- **Bluetooth disarming**  
- **Siren output 95dB @ 1m**  
- **Up to 128 RF devices, 240 user codes per area**  
- **Live visual streaming** via IP CAM or video door phone  
- **Remote control and event alert** through [Vesta Home 5 App](https://apps.apple.com/tw/developer/climax-technology-co-ltd/id438141751)
